## ComicBase Highlights

- **Issue-Level Rows:** ComicBase issue tracker stores series, number, and variant for a comic you already bought, which a book catalog cannot do cleanly.
- **Condition And Grade:** ComicBase comic database can note raw condition or a slab grade on copies you keep, so a Near Mint issue is not mixed with a reader copy.
- **Value On Your Copies:** ComicBase collection value is a running picture of titles you own, useful for insurance notes or a sale you actually plan, not for browsing other people's boxes.
- **What To Pick Up Next:** ComicBase pull list tracks series you already follow at a shop you use, so Wednesday is a checklist instead of a memory test.
- **Publishers And Creators:** Filters by publisher, writer, or artist help when a long box is sorted by title but you want every issue drawn by one name you collect.

## What Is ComicBase

ComicBase is a Windows database written for comic-book collections. It thinks in issues, not in ISBN-13 novels. A run of Amazing Spider-Man, a variant cover, a bagged annual, and a CGC slab are different rows. ComicBase issue tracker is the inventory. ComicBase comic database is the file that holds it.

Collectors open this program because a spreadsheet collapses once variants and grades appear. Pricing guides and value fields in ComicBase collection value are there for copies you possess. They are not a mandate to flip other people's collections. Cover scans, story notes, and storage-box IDs stay optional; the core is knowing which number is in which long box.

ComicBase is not a manga storefront and not a scan archive. Use it on issues you purchased, inherited, or were given. Teachers who keep classroom graphic novels they administer can use a simpler subset. Leave shop stock you do not own out of this file.

## Starting with ComicBase

Prerequisites: A PC you administer, comics in boxes or slabs you already own, and a rough idea of how those boxes are labeled.

1. **Prepare:** Pick one long box you own and stack it next to the keyboard so the first session matches real paper.
2. **Configure:** Create ComicBase comic database, set publishers you actually collect, and name storage locations after the boxes in the room.
3. **Test:** Enter a short run with ComicBase issue tracker, including one variant, and confirm the two covers stay on separate rows.
4. **Refine:** Add condition or a slab grade, then glance at ComicBase collection value for those copies only.
5. **Apply:** Work box by box. Use ComicBase pull list only for series you already buy at your shop.
6. **Maintain:** After each shop visit, mark new issues in, and remove rows for copies that left your collection.

## Best Uses

- **Long-Box Inventory:** ComicBase issue tracker is for numbered series in boxes you already keep.
- **Variant Hunting At Home:** Separate rows stop a cover search from hiding a copy you own.
- **Insurance Notes:** ComicBase collection value on titles you possess is easier to export than a pile of receipts.
- **Weekly Pull At Your Shop:** ComicBase pull list is a standing-order memory for series you already follow.
- **Creator Runs:** Filter by artist or writer across publishers when that is how you collect.
- **Classroom Graphic Novels:** A teacher can catalog copies that belong to the room.
- **Slab Versus Raw:** Grade fields keep a CGC copy from mixing with a reader.
- **Box Relabel After A Move:** Storage IDs in ComicBase comic database can match new box numbers.
- **Short-Box Silver Age:** Older numbering still fits issue-level rows.
- **Stop Mixing With Novels:** Keep prose books out of this file; this database is for comics you own.
- **Gifted Runs:** Inherited collections get their own storage location until you decide what stays.
- **One Collection Per File:** Do not merge a friend's boxes into your ComicBase issue tracker.
- **Annuals And Giant-Size:** Odd numbering still belongs on ComicBase issue tracker rows of copies you own.
- **Price Guide As A Note:** ComicBase collection value is a snapshot of your copies, not a store.
